## Standards：程式品質檢查（4 項，仍待修正）

以下為靜態檢查結果；未找到額外專案程式規範。

- **P1 舊錄音回呼可能污染新一輪錄音。** `Sources/LocalWriteCore/Speech/SpeechRecognizer.swift:82` 回呼缺少工作識別碼。取消後立即重新開始，舊回呼仍可能修改 latestTranscript 或取消新工作。`start` 也在 stateQueue 外修改共用狀態。建議將狀態操作統一隔離，並驗證工作識別碼。
- **P1 辨識失敗且尚無文字時，持續卡在錄音。** `SpeechRecognizer.swift:93` 僅在已有逐字稿時處理 error。建議所有錯誤都停止擷取、清理狀態並回報控制器。
- **P1 按停止後，尚未完成的授權 Task 仍可啟動麥克風。** `Apps/LocalWrite-macOS/LocalWriteController.swift:101` 在 await 授權後未驗證工作仍有效。建議儲存及取消 Task，並於恢復時檢查工作識別碼。
- **P2 剪貼簿還原會覆蓋新複製的內容。** `Apps/LocalWrite-macOS/TextInserter.swift:53` 在 250 ms 後無條件清除剪貼簿。建議比較寫入後的 changeCount，僅在內容未被其他操作更新時還原。

最嚴重的類型：錄音工作缺少可靠的生命週期與取消隔離。

## Spec：功能符合度檢查（5 項，仍待修正）

與 Standards 重複的問題在此保留，代表兩種檢查角度。

- **P1 空白語音／辨識錯誤缺少收尾。** `SpeechRecognizer.swift:93,145` 要求已有文字才處理錯誤或靜音。`Documentation/Testing.md` 明列 Empty speech。建議加入無語音逾時及錯誤回呼。
- **P1 靜音後可能遺失句尾。** `SpeechRecognizer.swift:156` endAudio 後立即以 partial 完成，173 行隨即取消 task。README 要求 preserve meaning / preserve intentional wording。建議停止音訊後等待 final，逾時才使用 partial。
- **P1 貼上失敗可能靜默丟失結果。** `TextInserter.swift:45` 未檢查事件建立及目標狀態；控制器在呼叫後立即清空逐字稿。`Documentation/MacOS-UX.md` 要求插入失敗顯示錯誤並保留文字。建議檢查可確認的失敗條件，保留可複製／重試的最終文字，勿將送出按鍵等同於貼上成功。
- **P2 剪貼簿還原競爭。** `TextInserter.swift:53` 的延遲還原可能覆蓋新 Copy。README 承諾還原原內容；需配合 changeCount 保護使用者的新操作。
- **P2 iOS 停止與錯誤路徑未釋放 audio session。** `Apps/LocalWrite-iOS/App/LocalWriteApp.swift:50,110,118` 提早返回，僅正常進入 refinement 的結尾會 deactivate。建議統一清理，以正常恢復其他音訊。

最嚴重的類型：語音句尾及貼上結果缺少可靠的保留與復原。

## 其他驗證觀察

- 編譯器仍指出 SpeechRecognitionResult／AVAudioPCMBuffer 跨佇列傳遞及視窗動畫 completion 的 actor 隔離警告。建議傳遞不可變的文字、布林值與音量數值，並將 UI 修改明確放在 MainActor。
- 中文 smoke test 保留了「嗯」，顯示移除填充詞的規格仍需固定評測語料驗證。一次結果只能證明模型呼叫成功。
- 優先順序建議：錄音工作生命週期 → final transcript 收尾 → 文字與剪貼簿保護 → 權限與多 App 人工測試。

## 重現指令

系統目前預設指向 Command Line Tools；以下只為命令指定已安裝的 Xcode。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test --scratch-path /private/tmp/LocalWrite-xcode-build
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project LocalWrite.xcodeproj -scheme LocalWriteMac -configuration Debug -derivedDataPath build CODE_SIGN_IDENTITY=- CODE_SIGNING_ALLOWED=YES build
open build/Build/Products/Debug/LocalWrite.app
```

測試及建置日誌：`/private/tmp/LocalWrite-tests.log`、`/private/tmp/LocalWrite-app-build.log`。模型測試日誌：`/private/tmp/LocalWrite-model-smoke.log`。
